# Critique: Raycast

## What it does well
Raycast's marketing site does something most "premium dark SaaS" sites don't: it commits to a distinct visual personality (specific gradient treatments, a recognizable icon/illustration style for features) rather than staying purely typographic. It proves a technical product site can have a strong graphic identity without sacrificing credibility with a technical audience.

## What to borrow
- **Committing to a distinct visual mark** — validates the core bet of `design/MechaTypographySystem.md`: a technical audience (developers, in Raycast's case) responds well to a product having actual visual personality, not just "clean and dark." Directly supports going with Mecha Typography instead of retreating to a safer, more generic system.
- **Feature-level visual variety within a consistent frame** — each feature/section gets its own illustration treatment while staying inside the same card/grid system. Useful pattern for `docs/playbooks/ProjectsSection.md`: each project card can have small unique visual details (different status tags, different metric callouts) while using the identical `PanelFrame` structure (`design/ComponentGuidelines.md`).

## Where to diverge
Raycast's illustration style is playful/colorful in a way that reads "developer tool with personality," not "engineer with deep technical credentials." ManhnhaPortfolio's Mecha Typography needs to stay closer to "precision instrument" than "fun app" — keep the accent palette narrow (`ColorSystem.md`) and avoid multi-color illustration sets even though Raycast's confidence in using them is worth admiring.

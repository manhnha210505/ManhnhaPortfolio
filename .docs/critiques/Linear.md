# Critique: Linear

## What it does well
Linear is probably the single most-cited reference for "technical product, premium execution" — dark UI, precise 1px borders, restrained motion, and a marketing site that reads like an extension of the actual product's design system rather than a separate "marketing skin." Copy is terse and confident, no filler adjectives.

## What to borrow
- **Border/line discipline** — Linear's UI leans on thin, precise borders and dividers instead of heavy shadows for structure. Directly usable for the Mecha Typography schematic linework and corner-bracket treatment (`design/MechaTypographySystem.md`) — the *precision* of a 1px line at the right opacity is what sells "technical," not thickness or glow.
- **Terse copy** — matches `branding/VoiceAndTone.md`'s "precise, understated" requirement almost exactly. Good calibration reference when writing Hero/About copy.
- **Dark theme elevation via subtle surface shifts**, not heavy drop shadows — relevant to `design/ColorSystem.md`'s background elevation-layer requirement.

## Where to diverge
Linear is also the site most likely to be named as *the* generic-AI-portfolio-clone reference right now — dark + thin borders + terse copy is table stakes for "this founder used Linear as a mood board" in 2026. The Mecha Typography system is what needs to carry the actual differentiation; Linear's execution quality (precision, restraint) is worth matching, but its specific visual vocabulary (that exact grey-on-near-black palette, that exact border treatment) should not be copied closely enough that a viewer thinks "this is a Linear clone with a cyan accent."

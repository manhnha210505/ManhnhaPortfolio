# Animation (Playbook Index)

This file does not redefine motion rules — it maps them onto sections. Full rules live in `docs/knowledge/motion/`.

| Section | Key motion moments |
|---|---|
| Hero | Load sequence, staggered headline/sub-headline/CTA reveal (`PageTransitions.md`, `AnimationPrinciples.md`) |
| About | Scroll-reveal of narrative text and education block |
| Skills | Card/tab hover states, grouped reveal by category |
| Projects | Image reveal on scroll-into-view, card expansion for case-study detail (`MicroInteractions.md`) |
| Contact | Form field focus states, submit success/error micro-interaction |
| Navbar | Active-section indicator, animated underline |

No section introduces a motion pattern not already defined in `motion/MicroInteractions.md` or `motion/MotionSystem.md` — this table is a lookup, not a new spec.

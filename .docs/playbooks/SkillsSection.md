# Skills Section

## Purpose
Scannable in 15-20 seconds (`profiles/Recruiter.md`) — grouped, not a flat tag cloud (`foundation/ProductRequirements.md`).

## Structure
Lead with the 4 confident core areas, secondary areas after — visual weight should reflect this ordering, not list everything at equal size.

### Core (lead, larger visual weight)
**Data Science / Statistics**
EDA & feature engineering · Applied statistics (distance metrics, precision/recall/F1) · Text data preprocessing (NLP tokenization)

**Machine Learning**
Classical: k-NN, Naive Bayes, Decision Tree, Gradient Descent, Logistic Regression, K-Means · Deep Learning: CNN, RNN/LSTM, Transformer, Vision Transformer (ViT) · Computer Vision (image captioning, encoder-decoder) · Model evaluation (BLEU, cross-validation)

**Data Visualization**
Matplotlib · Seaborn · Plotly

**MLOps**
Experiment tracking · Basic model deployment · Basic CI/CD

### Secondary (supporting, smaller visual weight)
**Backend & Cloud**
Next.js API routes/server actions · Supabase (DB, auth) · RESTful API design · Cloudflare (Pages/Workers, DNS) · Vercel

**Languages & Tools**
Python · TypeScript/JavaScript · SQL · scikit-learn, PyTorch/TensorFlow, pandas, NumPy · Next.js, React, Tailwind CSS, shadcn/ui, Framer Motion · Git, Jupyter, Docker

## Interaction
Grouped cards or tabs by category (not one long list) — hover/expand micro-interaction per `motion/MicroInteractions.md`. Consider a compact "core 4" visual (e.g. icon + one-line summary) as the first thing seen, with secondary skills a scroll/click deeper.

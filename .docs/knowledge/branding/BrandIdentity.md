# Brand Identity

## Who
ManhNha — a Data Science engineer whose personal brand is built on technical range (ML, AI, data viz, MLOps, backend, cloud) expressed through precise, uncluttered craft rather than loud self-promotion.

## Visual identity summary
Dark, editorial, minimal-but-premium (see `design/DesignPhilosophy.md`) — visual restraint signals confidence and technical maturity rather than needing decoration to prove competence. The signature element (open decision, see `foundation/ProductRequirements.md`) is the one place the brand allows itself to visibly "show off," and it must show off *technical* skill specifically (data, visualization, systems), not generic visual flair.

## Personality traits
- Precise, not vague
- Confident, not boastful
- Modern, not trendy-for-trend's-sake
- Warm enough to be memorable, not casual enough to undercut authority

## Consistency
Every touchpoint (site copy, project case studies, contact interaction) should be recognizably the same voice — see `branding/VoiceAndTone.md`.

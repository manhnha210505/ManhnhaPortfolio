# Voice & Tone

## Voice (constant across the site)
- **Precise** — claims are specific and verifiable ("reduced inference latency by 40% via X" beats "leveraged cutting-edge AI").
- **Confident, understated** — states accomplishments plainly, lets the work speak; avoids hype adjectives ("revolutionary," "game-changing").
- **Technically fluent but not jargon-walled** — a hiring manager without deep ML background should still follow the impact; a tech lead should still find the specificity they're looking for.

## Tone (varies slightly by section)
- **Hero/About**: warmest, most human — this is where personality shows.
- **Skills**: neutral, structured, scannable.
- **Projects**: narrative but grounded — problem → approach → impact (see `branding/Storytelling.md`), written like a project retro, not a sales pitch.
- **Contact**: direct and welcoming, minimal friction.

## Language
- v1 is English-only (see `foundation/ProductRequirements.md`); write for clarity to an international, English-reading audience — avoid idioms that translate poorly, since Vietnamese localization is planned for Phase 2.
